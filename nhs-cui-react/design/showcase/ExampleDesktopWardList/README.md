# ExampleDesktopWardList

A nursing ward list filtered, sorted and grouped through DataToolbar, FilterDialog and header filters, with region identifiers, the similar-name warning, update marks and task sublists. Below it, the handover list and the handshake that transfers responsibility.

## Components used

- PatientList
- PatientIdentificationCell
- DataToolbar
- FilterNotification
- FilterDialog
- HeaderCellFilter
- SortDialog
- SortIndicator
- SubList
- UpdateMarker
- HandoverTaskList
- HandshakeDialog

## Source

`examples/desktop-ward-list.tsx` in the package. Open `docs/site/desktop-ward-list.html` locally to switch region (GB, AU, NZ) and theme.
