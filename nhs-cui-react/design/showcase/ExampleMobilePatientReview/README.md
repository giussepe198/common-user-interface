# ExampleMobilePatientReview

The patient-first record (direction A): summary with the early warning score, medicines list, one-day drug chart and the full patient details sheet. A patient switch, from the ward list or a wristband scan, goes through PatientSwitchGuard and changes every screen.

## Components used

- MobileSummary
- MobileMedicationsList
- MobileDrugAgenda
- MobilePatientHeader
- MobileTabBar
- PatientDetailsSheet
- PatientSwitchGuard
- TouchButton

## Source

`examples/mobile-patient-review.tsx` in the package. Open `docs/site/mobile-patient-review.html` locally to switch region (AU, NZ, GB) and theme.
