# ExampleDesktopPrescribing

Search a formulary, prescribe in sentence layout, check against recorded allergies and current medicines (an unanswered High Priority alert holds Authorise, with the reason shown), preview and authorise. The authorised line joins the medications list, with its alert icon if one was raised.

## Components used

- PatientBanner
- DrugSearch
- SelectionTrail
- AlertItem
- PrescriptionForm
- PrescriptionPreview
- MedicationLine
- MedicationsList

## Source

`examples/desktop-prescribing.tsx` in the package. Open `docs/site/desktop-prescribing.html` locally to switch region (GB, AU, NZ) and theme.
