# ExampleDesktopPatientRecord

The record a clinician opens first: patient banner, current medications beside the allergy and adverse reaction summary, and the early warning score, key observations and decision support alerts.

## Components used

- PatientBanner
- MedicationsList
- AdrSummaryList
- EarlyWarningScoreSummary
- GraphStack
- AlertContainer

## Source

`examples/desktop-patient-record.tsx` in the package. Open `docs/site/desktop-patient-record.html` locally to switch region (GB, AU, NZ) and theme.
