# NHS CUI source documents

The NHS Common User Interface guidance documents used to build the library in `../nhs-cui-react`, as retrieved from the UK Government Web Archive (National Archives) snapshot of systems.digital.nhs.uk.

- `manifest.json` lists every document with its original title, archive url, copyright line and licence status.
- `links.json` lists the archive urls.
- Four documents co-owned by Microsoft Corporation are not included (`"redistributed": false`); read them at their archive urls.

See `../NOTICE.md` for the licence terms and attribution.
