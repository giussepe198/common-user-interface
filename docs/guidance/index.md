# Reading the original guidance

The collection contains 45 distinct transcriptions with their retained extracted images. It complements the implementation-focused guidance notes; it does not replace them.

Each page links to a local source PDF. The build verifies that PDF against the repository's existing canonical archive and stages it into the generated site. No network service or PDF conversion package is needed to build or read the site.

Original "correct" and "incorrect" figures illustrate the relevant design rule, not a requirement to copy old decorative styles. Some extracted images are logos or small fragments rather than full diagrams. PDF table extraction remains imperfect, and legacy wording and references are intentionally preserved. Consult the PDF if a detail is ambiguous.

The contributed collection deliberately excludes four Microsoft-co-owned documents and their derived images/text, matching the source-document archive's existing policy. It also excludes a duplicate full patient-banner download that the restoration's old link metadata had mislabelled as a quick guide. The actual Patient Banner QIG and other additional upstream documents can be transcribed in later contributions.

See [preservation and terms](../preservation.md) for provenance, attribution, exclusions and verification.
